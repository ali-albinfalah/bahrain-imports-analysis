# Bahrain Fast Fashion Import Analysis 2021–2025

## Overview
Analysis of Bahrain's clothing import data from 2021 to 2025 to identify
high-demand categories, key sourcing countries, cost-effective suppliers,
and seasonal demand patterns — delivered as a consulting project for a
fictional fast fashion startup (ROVE).

**Type:** Group Project   
**Tools:** Python (Pandas), Power BI   

## Problem Statement
A Bahraini entrepreneur launching a fast fashion brand lacks visibility into
which clothing categories drive import demand, how trends have evolved
from 2021 to 2025, and which sourcing markets dominate Bahrain's supply.

## Objectives
- Identify the highest-demand clothing categories by import volume and value
- Analyze import trends from 2021 to 2025 to detect growth patterns
- Determine the main countries supplying clothing to Bahrain
- Identify the most cost-effective sourcing countries
- Evaluate potential market gaps and underserved product segments

## Key Findings
- Bahrain's clothing import market grew by nearly 40% in value from 2021 to 2024
- Total import value across the period reached approximately 391.6M BHD
- T-shirts lead in volume while Trousers/Shorts lead in total import value
- Women's dresses represent a niche premium opportunity with lower competition
- China dominates by quantity; India and Bangladesh offer the lowest cost per item
  (averaging 2 BHD per unit) compared to Italy at 42 BHD per unit
- Import values peak in January–March and December, suggesting seasonal inventory
  builds should be ordered from suppliers in October–November

## Recommendations
- Lead product range with T-shirts, Trousers, and Dresses
- Source core products from India or Bangladesh for cost efficiency
- Time inventory orders for October–November to meet peak demand months
- Explore China for product variety alongside affordable Asian suppliers
